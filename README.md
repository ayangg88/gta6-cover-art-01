SUNSET COVER STUDIO is an original GTA-style cover art maker that turns a photo and a caption into a multi-panel poster cover with a sunset or neon grade, exported as a PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080.
Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

The app then opens at http://localhost:8080.
